
# IoT Threat Detection - QA Testing Checklist

## Purpose
This document provides a checklist for manually
evaluating the functionality, security, and usability
of the IoT Threat Detection System.

## Functional Testing
- [ ] Verify that the dashboard loads correctly.
- [ ] Verify that valid users can log in.
- [ ] Verify that invalid login attempts are rejected.
- [ ] Verify that threat detection results are displayed.
- [ ] Verify that navigation works correctly.

## Security Testing
- [ ] Check access to protected dashboard pages.
- [ ] Verify role-based access restrictions.
- [ ] Check whether logout ends the session.

## Usability Testing
- [ ] Check dashboard readability.
- [ ] Check buttons and navigation.
- [ ] Check error messages.
- [ ] Check the dashboard on different screen sizes.
